# Expected Actions

This document describes the expected firewall actions for all traffic generated by the demo traffic generator. These actions correspond to the policy defined in [all-actions-test.json](all-actions-test.json).

## Security Rules

Ping tests to specific destination addresses:

| Destination | Firewall Action | Expected Result |
|-------------|----------------|-----------------|
| 9.9.9.9 (Quad9) | block/alert/log | Traffic blocked |
| 1.1.1.1 (Cloudflare) | reject/alert/log | Traffic rejected |
| 94.140.14.14 (AdGuard) | accept/alert/log | Traffic allowed |

## IP Reputation

IP and URL reputation targets can be assigned to specific Docker client IPs in the Configuration tab. Three templates are provided for specific client IPs to generate all actions (block/reject/alert).

| Threat Level | Firewall Action | Expected Result |
|-------------|----------------|-----------------|
| Malicious | block/alert/log | Traffic blocked |
| Non-malicious | log | Traffic allowed |

## IDPS (Intrusion Detection/Prevention)

Each Suricata signature has a default action and an actual (policy-overridden) action. The traffic generator runs a curl command per signature and checks whether the traffic was blocked or allowed as expected.

| SID | Description | Default Action | Actual Action | Expected Result |
|-----|-------------|---------------|---------------|-----------------|
| 2049400 | /etc/passwd Detected in URI | alert | block | Traffic fails (blocked by policy) |
| 2033891 | Suspicious Request nc.exe in URI | alert | reject | Traffic fails (rejected by policy) |
| 2029923 | IP Check (ip.jsontest.com) | alert | alert | Traffic passes (alert only) |
| 2007337 | UNION SELECT SQL Injection | reject | block | Traffic fails (blocked by policy) |
| 2006124 | detail.asp UNION SELECT SQL Injection | reject | reject | Traffic fails (rejected by policy) |
| 2005082 | faq.php UNION SELECT SQL Injection | reject | alert | Traffic passes (alert only). Note: may not pass if an upstream firewall blocks the request |
